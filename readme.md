
## ⚡ Calculadora de Consumo ElétricoUma
 ferramenta simples em Python desenvolvida para calcular o consumo de energia de aparelhos elétricos e estimar o impacto financeiro na conta de luz mensal.

 ## 👤 AutorCarlos Marcelo

 ## 💻 Sobre o Projeto
 Este programa foi criado para calcular o consumo de um aparelho elétrico e estimar o seu gasto mensal em reais (R$), baseando-se na quantidade de horas de funcionamento diário e na tarifa média de energia.

 ## 🧮 Como Funciona (Fórmulas)
O script utiliza os seguintes cálculos para definir a estimativa mensal:

* **Consumo Mensal (kWh):**
  `Consumo = (Potência em Watts * Horas por Dia * 30) / 1000`

* **Custo Mensal (R$):**
  `Custo = Consumo Mensal * Preço do kWh`

*(Tarifa padrão configurada no sistema: **R$ 0,75 por kWh**)*

## 📝 Instruções de UsoAo iniciar o programa, basta interagir com o terminal digitando as informações solicitadas:
 Digite o nome do aparelho elétrico (ex: Ar Condicionado).
 Digite a potência do aparelho em Watts (ex: 1500).
 Digite o tempo médio de uso diário em horas (ex: 8).
 O programa exibirá o resumo do consumo em kWh e o valor estimado em Reais.
